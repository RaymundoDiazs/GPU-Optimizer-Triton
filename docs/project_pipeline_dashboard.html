Formal Grammar Contract

This is the narrow EBNF target for vector_add. It is intentionally not a universal Python grammar; it defines the shape of one valid Triton kernel family.


      


      

        
XGrammar Direction

        
Current grammar checks mostly happen after generation. The XGrammar target is to restrict tokens during generation so invalid branches are harder to produce.

        

      

    


    

      

        
Shape-Aware Decision

        
Move the tensor size. The grid changes because the shape controls how many Triton programs are launched.

grid = ceil(N / BLOCK_SIZE). This is why shapes belong in the generation strategy, not only in runtime tests.
